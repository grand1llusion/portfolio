# Bradley Papke · Portfolio

My personal portfolio: About me, Tech superpowers, and Projects, hosted on **AWS Amplify Hosting**.

**Creative feature: the Secure Terminal.** Press the `>_` button (or the backtick key) to open a terminal over
the page. Type `help`, follow my career with `traceroute career`, and hunt for three hidden flags. Find them
all to unlock a "you'd pass my course" certificate. The rest of the site works without it.

- `portfolio.md`: the plan the site was built from
- `index.html`, `styles.css`, `script.js`: the whole site, no build step
- `images/headshot.jpg`: profile photo

Built with an AI coding agent following AWS Builder Center's "Build your website on AWS" series.
